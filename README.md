# Options-Tracker

An automated Python application designed to track, fetch, and log options trading positions seamlessly, eliminating manual portfolio management.

## Features
* Integrates with the Webull SDK to automatically fetch live trading position data.
* Connects to a MySQL database to securely store, structure, and query historical trading details.
* Automated containerization setup using Docker for smooth deployment and database management.

## Tech Stack
* Python (Webull SDK, MySQL Connector)
* Docker & Docker Compose
* MySQL
